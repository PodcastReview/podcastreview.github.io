《大学怎样对抗 AI 作弊》

按中文文章的段落顺序，左侧保留中文文本，右侧列出用于核对的英文材料。

01

1876：反监考与“信任培养诚实”

财新中文原文
1876年，普林斯顿大学校报《普林斯顿人》发表社论，反对学校安排监考。 社论认为，预先把学生当作潜在的骗子是糟糕的道德教育；给予他们信任，反而更易培养诚实。 文章建议，考试结束时由学生签署承诺，声明自己既没有给予也没有接受他人帮助，教授和助教可去处理“比监视作弊更有意义的事情”。
英文材料
The Atlantic｜Rose Horowitch
1876 Princetonian → anti-proctoring → “bad moral education” → honor pledge → “better business than watching for fraud.”
02

1893 Honor Code → 133年 → 历史危机序列 → AI → 恢复监考

财新中文原文
1893年，这套安排正式发展为普林斯顿著名的“荣誉准则”：考试开始后，教授离开教室，学生自行维持秩序；发现作弊者有义务举报，受到指控者由同龄人组成的委员会审理。 此后133年间，这项制度挺过了两次世界大战、上世纪60年代校园动荡、水门事件带来的信任危机，以及搜索引擎和维基百科的冲击。 最终让它难以维系的是生成式人工智能。2026年5月，普林斯顿教师投票决定重新引入监考……荣誉准则在名义上仍然存在……一个曾靠荣誉维持的制度，如今要靠监督来保障。
英文材料
The Atlantic｜Rose Horowitch
1893 Honor Code → professors leave → peer reporting/jury → 133 years → 2026 proctoring vote.
03

Brown：枪击 → take-home → ChatGPT → 线下 final → 退课/坠分

财新中文原文
同年春天，布朗大学经济学教授罗伯托·塞拉诺经历了另一场信任危机。受校园枪击事件影响，他把期中考试改为居家进行， 结果成绩高得反常，不少答案与ChatGPT生成的内容高度相似； 期末恢复现场闭卷后，成绩大幅下降，一批期中获得满分的学生选择退课。两次考试的落差，让AI作弊从难以证实的怀疑变成无法回避的现实。
英文材料
Inside Higher Ed｜Emma Whitford
take-home midterm → 96% average → ChatGPT-like answers → in-person final 48.6% → 18 drops.
04

学校无回应 → 公开后才行动；后半进入制度解释

财新中文原文
比学生作弊更严重的，是布朗校方的消极态度。塞拉诺教授提交证据后，学术规范委员会长期没有回应，直到媒体曝光，调查才终于启动。 这或许因为大学尚未找到处理AI作弊的有效办法，也可能反映了更深层的制度性逃避——在学生越来越被当作教育消费者的高等教育市场中，追究作弊会招致投诉、增加程序成本，还可能损害学校形象；拖延处理却几乎没有代价。 于是，教授独自承担取证、举报、应对申诉的压力，管理者则躲在背后等待争议随学期结束而消散。
英文材料
Inside Higher Ed｜Emma Whitford
May submission → no response → public disclosure → individual complaints. “Their time is not compensated.” 中文后半制度解释未在该原段完整出现。
05

过去作弊需要 effort → 网络降门槛 → AI 推到极端

财新中文原文
AI没有发明作弊，却彻底改变了作弊的成本。过去，学生需要准备小抄、寻找代写或抄袭同学答案；如今，只需把题目输入对话框，几分钟内便能获得结构完整、语言自然的答案。 模型还能模仿个人文风，故意制造错别字，降低被识别的概率。 作弊因此变得廉价、便捷而隐蔽，传统荣誉制度赖以维持的心理门槛也随之崩塌。
英文材料
The Atlantic｜Rose Horowitch
cheating once required effort → internet lowered barriers → AI “new extremes” → mimic style / add typos.
06

501 → 30% → 28% → 45%

财新中文原文
在一项501名毕业生参与的调查中，30%承认曾作弊，28%承认在禁止使用ChatGPT的作业中使用过它，45%知道同学作弊却没有举报。
英文材料
The Atlantic｜Rose Horowitch
501 respondents → 30% cheated → 28% prohibited ChatGPT use → 45% knew peer cheating and did not report.
07

“大家都在作弊” → 守规则者吃亏 → 成绩竞争

财新中文原文
荣誉准则依靠的不只是个人良心，还包括对同伴行为的预期。当越来越多人相信“大家都在用”，遵守规则便容易显得像自愿接受竞争劣势。 认真复习的学生付出更多时间，却要与机器生成的满分答案竞争；奖学金、推荐信、研究机会和工作岗位，也会在失真的成绩体系中被重新分配。
英文材料
The Atlantic｜Rose Horowitch
rule-followers feel disadvantaged → perceived cheating encourages more cheating. 中文后半奖学金 / 推荐信 / 工作岗位链，本页暂不列英文对应。
08

Princeton economics → Brown economics：学校名称变化

财新中文原文
目前，普林斯顿大学选择增加监考、减少居家考试、恢复课堂手写。 布朗大学经济系计划要求学生口头答辩， 部分教师要求保留Google Docs修改记录。
英文材料
The Atlantic｜Rose Horowitch
take-home exams down >⅔ → economics oral defense → Google Docs revision history.
09

surveillance 回归 → 教师更警惕 → 教学关系改变

财新中文原文
这些措施会提高考核的可信度，也会改变大学的气氛。教师开始怀疑每一篇过于流畅的论文，学生也知道教师正在怀疑自己。 作业设计越来越围绕防范作弊展开，口试、闭卷考试和身份验证不断增加。 教师投入大量时间确认作品由谁完成，留给讨论质量的精力相应减少。
英文材料
The Atlantic + The New Yorker
surveillance → faculty mistrust → “plagiarism cop” → oral finals difficult to scale.

11

“双向信任正在瓦解”

财新中文原文
这或许构成AI给高等教育带来的最深刻变化。大学长期把学生当作能为自己行为负责的成年人，学生则相信成绩能够大致反映个人能力、学校会保护公平竞争。 如今这种双向信任正在瓦解：一边出现批量生产的虚假成绩，另一边出现迟缓、犹豫甚至逃避责任的管理程序。
英文材料
The Atlantic + The New Yorker
faculty more wary; students notice → “erosion of trust”.
12

合理AI用途 → learning objectives → process over product

财新中文原文
大学无法通过封禁AI回到过去。资料检索、语言润色、代码调试和思路整理都能成为合理学习方式。 每门课需要重新说明考查目标，区分可借助工具的环节与必须由学生展示的能力。
英文材料
Brown University GAITL
explanation / revision / self-testing / summarizing / debugging → learning objectives → “process over product”.
13

1876 首尾回环 + diploma / trust

财新中文原文
1876年的普林斯顿社论相信，给予学生体面能够培养值得信任的人。这个判断至今仍有价值，但信任不是对违规视而不见。 学生作弊时，大学需要追究；教授举报时，大学需要回应；守规矩的学生承担更高成本时，大学需要保护他们。
英文材料
The Atlantic｜Rose Horowitch
diploma as trust signal → 1876 “rogue / scholar” warning returns.
14

“教育的表演 / 评价的表演 / 能力的表演”

财新中文原文
AI带来的已不只是考场管理问题，而是一场大学的生存危机。大学之所以值得存在，在于它能够证明学生经历了真实的学习，获得了可检验的知识与能力。一旦成绩可以由机器批量制造，学校又不愿追究，大学便会逐渐丧失证明能力。 课堂成为教育的表演，考试成为评价的表演，文凭成为能力的表演，大学最终只剩下一套昂贵而体面的仪式。
英文材料
The Atlantic + The New Yorker + Brown GAITL
diploma signal weakens → “simulacrum of education” → process / demonstrated skills.
